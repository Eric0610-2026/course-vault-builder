# Existing-course compatibility

Use this checklist when extending an established course vault. It is a workflow guide, not an inventory of any particular user's courses. Re-read the live folder before every edit; never rely on old counts, file names, page totals, or link audits as current facts.

## Before editing

- Determine the actual Obsidian vault root and the course project root; preserve the course path prefix in links when multiple courses share one vault.
- Read the course home page, folder guide, source index, relevant notes, and existing templates. Preserve established headings, property names and languages, source locations, and conversion formats.
- Classify files as synthesized notes, topic notes, per-page records, or faithful source-format conversions. Do not apply a chapter scaffold or new captions to a faithful conversion unless the user requests reformatting.
- Inventory source files at their current locations. Keep existing sources and note paths unchanged during ordinary incremental additions; migrate them only when the user asks.

## Common differences to preserve

- Course folders can have different chapter counts, topic notes, per-page records, and templates. Do not create empty folders to make them look uniform.
- Existing courses may use different frontmatter property names or languages. Preserve them unless a requested view or migration requires a deliberate change.
- A reference-conversion note may preserve original questions, answers, tables, emphasis, and authorship; this does not certify the answers or permit generating new quizzes.
- Check source references against the live files. A previously reported page count, audit result, or missing-file list is historical until rechecked.

## Table formatting

Use [table formatting](table-formatting.md) for caption, alignment, full-width styling, and source placement. When a task edits tables in an existing course, preserve its data and meaningful `来源` fields; remove only redundant citation columns when a single source location is centralized in the caption.
